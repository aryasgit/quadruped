# BARQ v1 — from-scratch control stack

Revival of the v1 quadruped (2026-06). Everything in `stack/` is new code;
the legacy stack under `src/` is kept as **reference only** — its one
load-bearing artifact, the measured hardware truths, has been ported to
[`barq1/truths.py`](barq1/truths.py).

Research reference: [mike4192/spotMicro](https://github.com/mike4192/spotMicro)
(cloned read-only at `~/barq_v1/reference/spotMicro`). The robot uses the same
chassis/mechanics/URDF; only the servos (DS3240MG 40 kg·cm, 270°) and compute
(Jetson Orin Nano) differ.

## Hardware facts (measured — see `barq1/truths.py`)

| Fact | Value |
|---|---|
| I2C bus / PCA9685 / MPU6050 | bus **7** / `0x40` / `0x68` |
| PWM frame | **50 Hz** (prescale 121) |
| Servo pulse range | **106–535 ticks** ≈ 518–2612 µs ↔ 0–270° |
| Canonical unit | PCA9685 **ticks** (all truths were measured in ticks) |

## Setup (one-time, workspace-local)

All dependencies live in the **workspace venv**, never system-wide, so
nothing can conflict with `~/barq_ws` (v2):

```bash
~/barq_v1/venv/bin/pip install -r ~/barq_v1/quadruped/stack/requirements.txt
```

## Servo calibration GUI

```bash
# on the Jetson
cd ~/barq_v1/quadruped
~/barq_v1/venv/bin/python stack/tools/calibration_gui.py          # port 8035
# on the Mac
open http://barq.local:8035
```

- Starts with **all outputs OFF** (servos limp). If the PCA9685 is unpowered
  the GUI runs in **SIMULATION** mode (amber badge) — everything works except
  real I2C writes.
- Per servo: slider/nudge in ticks (clamped to the measured mechanical window;
  "full range" unlocks the electrical 106–535), off = free-wheel,
  go-to perp/stand references from the truths.
- **Method (spotMicro `docs/servo_calibration.md`):** position each link at its
  0° reference → *Set TRUE ZERO*, then at one more known angle (±90° for links
  2–3, ±45° for link 1) → *Record*. The GUI fits
  `ticks = zero + slope·angle` and *Save* writes
  `stack/config/servo_calibration.yaml`.
- **ESC / red button = ALL OFF.** Keep the robot on a stand, legs hanging free.

## Safety notes

- Enabling a servo snaps it to the slider value — no soft-start exists at the
  PWM level. Position the link by hand near the target first (output off).
- Pose buttons stagger servo starts by 120 ms to soften current inrush.
- Drive servos from the 40 A BEC rail, never the Jetson 5 V header.
